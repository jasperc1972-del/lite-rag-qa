# 輕量 RAG 檢索問答 — 使用手冊（R1）

▶️ **示範影片**：https://www.youtube.com/watch?v=KsfMsHeP24w

---

## 1. 這是什麼？

把你的文件（PDF、Word、Markdown、TXT）放進去，就能用一般說話的方式提問。系統會先從文件裡找出最相關的段落，再請 Claude 根據這些段落回答，並告訴你答案出自哪個檔案、第幾頁或第幾段。

Claude 只會根據你的文件回答；文件裡沒寫的，它會直接說「**文件中找不到相關資訊**」，不會自己編造。

## 2. 名詞小辭典

| 名詞 | 白話解釋 |
|---|---|
| 索引 | 事先把文件整理成「找資料用的目錄」。每份文件只要建立一次，之後就能一直問。 |
| 切片 | 把文件切成一小塊一小塊（每塊最多 500 字），方便精準找到相關段落。 |
| Embedding | 把文字轉成代表「意思」的數字。意思相近的句子數字也相近，所以能照意思搜尋，不必關鍵字完全相同。 |
| 檢索 | 依照你的問題，從索引中找出最相關的 4 塊切片。 |
| 來源標註 | 回答下方列出的出處，例如「規格書.pdf p.3」或「手冊.docx 第 2-4 段」。 |
| API Key | 使用 Claude 的通行密碼，存在 `.env` 檔案裡，不可外流。 |

## 3. 第一次安裝

> 需要 Windows、Python 3.10 以上（建議 3.13；3.15 太新，PyTorch 可能無法安裝）。

### 3.1 下載程式並安裝套件
```
git clone https://github.com/jasperc1972-del/lite-rag-qa.git
cd lite-rag-qa
py -3.13 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
套件約 1.5～2 GB（主要是 PyTorch），需要幾分鐘。第一次啟動時還會自動下載 Embedding 模型（約 470 MB）。

### 3.2 申請 Claude API Key
1. 到 https://platform.claude.com 註冊／登入。
2. **Billing** → 購買額度（最低 US$5，測試已足夠）。
   - 企業稅務編號：個人留空即可。
   - 自動儲值：建議「暫時略過」，避免意外扣款。
3. 回到 Dashboard → **取得 API 金鑰** → **Create Key** → 立刻複製（只顯示一次）。

> Claude.ai 的 Pro／Max 訂閱與 API 分開計費，訂閱不含 API 額度。

### 3.3 填入 API Key
1. 把 `.env.example` 複製一份，改名為 `.env`。
2. 用記事本開啟 `.env`，把 `your_actual_api_key_here` 換成你的 Key，存檔：
   ```
   ANTHROPIC_API_KEY=sk-ant-xxxxxxxx...
   ```
   等號前後不要有空格，也不要加引號。

## 4. 啟動與關閉

### 4.1 啟動
1. 雙擊專案資料夾裡的「**啟動.bat**」，會出現一個黑色視窗。
2. 約 6 秒後瀏覽器會自動打開程式畫面；若沒有，請在網址列輸入 `localhost:8501`。

小技巧：在「啟動.bat」上按右鍵 →「傳送到」→「桌面（建立捷徑）」，以後從桌面雙擊即可。

### 4.2 關閉
直接關閉黑色視窗即可。已建立的索引會保留，下次啟動仍在。

### 4.3 注意
- 黑色視窗在使用期間不要關掉，它就是程式本體。
- 程式只能在這台電腦上使用，同網路的其他電腦無法連線（保護你的文件）。

## 5. 畫面介紹

```
┌────────────┬──────────────────────────────────┐
│ 側邊欄      │  📚 輕量 RAG 檢索問答              │
│            │  [📁 文件管理]  [💬 問答]   ← 分頁  │
│ 已索引檔案   │                                  │
│   🗑 刪除   │  （分頁內容）                      │
│ 🔄 重建索引  │                                  │
│ 🧹 清除對話  │                                  │
│ 模型資訊    │                                  │
└────────────┴──────────────────────────────────┘
```

| 區域 | 用途 |
|---|---|
| 📁 文件管理 分頁 | 上傳文件、建立索引、查看解析結果與切片內容 |
| 💬 問答 分頁 | 輸入問題、查看回答與參考來源 |
| 左側側邊欄 | 查看已索引檔案、刪除檔案、重建索引、清除對話紀錄 |

## 6. 步驟一：上傳文件、建立索引

1. 在「📁 文件管理」分頁，閱讀藍色提示框（列出可上傳與暫不支援的格式）。
2. 勾選「**我已確認要上傳的檔案皆為可上傳格式**」。未勾選前無法上傳。
3. 按「Upload / Browse files」選擇檔案，或直接拖進上傳區，可一次多選。
4. 按「**📥 建立索引**」，等待進度條跑完。第一次會稍久（載入模型）。
5. 看到綠色「✅ 檔名：讀到 N 頁/段，切成 N 塊」即成功；紅色「❌」會說明失敗原因。

同一份文件內容更新後重新上傳即可，系統會自動覆蓋舊索引，不會重複。

## 7. 步驟二：提問

1. 切換到「💬 問答」分頁。
2. 在最下方輸入框打字，按 Enter 送出。
3. 回答中的 `[1]`、`[2]` 代表依據的片段編號；下方「📎 參考來源」列出對應的檔名與頁碼／段落。
4. 想核對答案，展開「檢視本次檢索到的 N 個片段」可看原文與相似度。
5. 可以接著追問，系統會記得前面的對話。

### 7.1 問得好的技巧

| 建議 | 範例 |
|---|---|
| 一次問一件事 | ✔「M6 螺絲扭力多少？」 ✘「螺絲扭力、保固、請假規定各是什麼？」 |
| 用文件裡可能出現的說法 | ✔「保固期間多久？」 |
| 要比較時說清楚對象 | ✔「R1 和 R2 支援的格式差在哪？」 |
| 換主題前先清除對話 | 按側邊欄「🧹 清除對話紀錄」 |

## 8. 管理文件

| 想做的事 | 怎麼做 |
|---|---|
| 確認文件有沒有讀對 | 文件管理分頁「索引內容預覽」→ 展開「🔍 檔名」；按「再顯示 5 塊」看更多 |
| 匯出解析結果 | 展開「🔍 檔名」後按「匯出 .txt」或「匯出 .jsonl」 |
| 刪除某份文件 | 側邊欄該檔名右邊的 🗑；刪除後提問不會再引用它 |
| 全部重新建立索引 | 側邊欄「🔄 重新建立索引」：用已上傳過的原始檔重新解析 |
| 清除對話 | 側邊欄「🧹 清除對話紀錄」（不影響索引） |

## 9. 可以放哪些檔案

| 類別 | 格式 | R1（目前） | 預計 |
|---|---|---|---|
| A 文字型 | PDF（有文字層）、Word `.docx`、`.md`、`.txt` | ✔ 可上傳 | — |
| B 表格型 | Excel `.xlsx`、`.csv` | ✘ 不可 | R2 支援 |
| C 圖片／掃描型 | `.png`、`.jpg`、掃描型 PDF | ✘ 不可 | R3 支援 |

- **判斷 PDF 有沒有文字層**：用閱讀器打開，能用滑鼠選取並複製文字的就有；只能框選成圖片的是掃描檔。
- 舊版 `.doc` 請用 Word 開啟後「另存新檔」為 `.docx`。

## 10. 費用與模型

- 每問一題約 0.01～0.02 美元（Sonnet 5.5）。上傳、建立索引、預覽都在本機進行，不花錢。
- 餘額可到 platform.claude.com 的 Dashboard 查看「組織點數」。
- 想更省錢：把 `.env` 的 `CLAUDE_MODEL=claude-sonnet-5-5` 改成 `claude-haiku-5-5`，存檔後重新啟動程式。

## 11. 常見問題與錯誤訊息

| 看到的訊息／狀況 | 原因 | 處理方式 |
|---|---|---|
| 上傳區是灰色的 | 還沒勾選確認 | 勾選「我已確認…」 |
| 為掃描型 PDF，請改於 R3 版本使用 | PDF 沒有文字層 | 目前無法使用；改找有文字的版本 |
| 將於 R2／R3 支援 | 格式本版不支援 | 見第 9 節 |
| 編碼無法辨識 | TXT 編碼特殊 | 記事本開啟 →「另存新檔」→ 編碼選 UTF-8 |
| 文件中找不到相關資訊 | 文件裡沒有答案，或問法差太多 | 換個說法、確認文件已建立索引 |
| 尚未設定 ANTHROPIC_API_KEY | `.env` 沒填 Key | 填入 Key 後重新啟動 |
| API Key 無效 | Key 貼錯、複製到其他類型憑證，或已刪除 | 到 Console 的 API Keys 重建，更新 `.env` 後重新啟動 |
| 請求太頻繁或額度不足 | 餘額用完 | 到 Console 的 Billing 加值 |
| 無法連線到 Claude | 網路中斷 | 檢查網路後再試 |
| 瀏覽器無法連上 localhost | 程式沒在執行 | 雙擊「啟動.bat」，黑色視窗保持開著 |

## 12. 隱私與安全

- 文件、切片與索引都存在本機（`chroma_db\` 與 `uploads\`），不會上傳到 GitHub。
- 只有「你的問題＋檢索到的幾小段文字」會送到 Claude 回答，整份文件不會上傳。
- API Key 只存在 `.env`，不要貼到對話、截圖、錄影或傳給別人；外流時到 Console 刪除並重建。
